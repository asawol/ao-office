# 아사월 시청 · 비서실

아사월님의 Pickle **크림**(비서실장)이 쓰는 3D 아이소메트릭 가상 청사.
청사 공간을 눌러 부서별 현황을 보고, AI 공무원과 회의실에서 대화하고, 지시메모를 함께 남깁니다.

- 라이브: https://asawol.github.io/ao-office/
- 저장소: https://github.com/asawol/ao-office

## 화면

| 탭 | 내용 |
| --- | --- |
| 청사 | 3D 디오라마 + 공간 핫스팟 핀, 히어로 카드, 모션 토글, 지금 이 순간 |
| 회의실 | 실시간 대화, AI 공무원 답장, 빠른 지시, 참여 부서 |
| 부서 | AI 공무원 임명·수정·전출, 부서 on/off |
| 결재현황 | 시장님·부서·연결된 피클 상태, 시스템 정보 |
| 지시메모 | 함께 쓰는 지시 보드 (실시간 동기화) |

- 헤더: `市` 모노그램, `아사월 시청`, `시청 비서실 · N개 부서 근무 중`, `● LIVE` / `로컬` 연결 표시, 초대 링크·설정.
- 모바일 우선(≤492px) 단일 컬럼, 900px 이상에서 2컬럼 데스크톱 레이아웃.
- 폰트 Pretendard, 카드 radius 20px, hairline `#e6e8ec` 테두리, 배경 `#f5f6f8`.

## 동작

- `js/net.js` — 공개 MQTT 브로커(WSS) + BroadcastChannel 실시간 동기화, 같은 `room`이면 서로 이어집니다.
- `js/mqtt-lite.js` — 의존성 없는 최소 MQTT 3.1.1 WebSocket 클라이언트.
- `js/app.js` — UI 렌더링, AI 공무원 답장 엔진, localStorage 저장, 초대 링크.
- 상태 저장 키: `cityhall-office-v7` (이름 · 소개 · 색상 · 청사 코드 · 모션 · 부서 · 지시메모 · 최근 대화 60개).
  이전 키 `cityhall-office-v6`·`cityhall-office-v5`·`cream-office-v4`의 값은 처음 열 때 직위·부서명과 문구를 시청 체계로 정리해 이어받습니다(메모·대화의 뜻은 그대로).
  옛 이름(`지휘`, `기획·일정`, `기획예산과`, `기획실`, `개발·리서치`, `정보통신과`, `정보화과장`, `총무·운영`, `간부회의실`, `민원·휴게실`)은 불러올 때 자동으로 `비서실장`, `기획실장`, `정보화 주무관`, `총무과장`, `회의실`, `휴게실`로 바뀝니다.

## 메시지 규약 (net.js)

- `hello` / `state`: 접속 알림과 20초 하트비트
- `chat`: 회의실 대화 (이름 · 직위 · 색상 · 시각)
- `tasks`: 지시메모 보드 전체 목록 + rev
- `bye`: 나갈 때
