# 🏢 합동 피클 비서실

피클들이 함께 쓰는 가상 오피스입니다. 캐릭터(피클)로 사무실을 거닐고, 인사하고, 업무 메모를 같이 남길 수 있습니다.
바닥은 우드·카펫 타일, 방은 유리 파티션으로 나뉜 현대 오피스 톤으로 구성되어 있습니다.

- **주소**: https://asawol.github.io/ao-office/
- **초대 링크**: 주소 뒤에 `?room=방이름` 을 붙이면 같은 방 피클끼리 만납니다. (기본 방 `asawol-office`)
  - 예: `https://asawol.github.io/ao-office/?room=team-a`

## 상주 AI 동료

혼자 쓸 때도 사무실이 돌아가도록 **AI 동료 3명**이 기본으로 함께 있습니다.

| 동료 | 역할 | 담당 구역 |
| --- | --- | --- |
| 민지 | 기획·일정 | 워크스테이션 |
| 도현 | 개발·리서치 | 포커스 팟 |
| 서연 | 총무·운영 | 탕비실·라운지 |

- 명단에 `AI` 배지가 붙고, 이름표에도 역할과 `AI` 표시가 붙어 실제 접속자와 구분됩니다.
- 몇 초~몇십 초마다 자리를 옮기고, 데스크·회의실·탕비실에서 머물며 상태(업무중·회의중·자리비움)를 바꿉니다.
- 대화창에서 **이름을 부르거나**(예: `민지야, 이번 주 일정 확인해 줘`) 궁금한 일을 물으면, 역할에 맞는 동료가 말풍선과 함께 짧게 답합니다. 업무 메모에는 가끔 한 번씩만 반응합니다.
- 상단 **`+ AI 동료`**에서 이름·직무·담당 구역·색상을 골라 추가하고, 켜고 끄거나 내보낼 수 있습니다. 목록은 이 브라우저(`localStorage`)에 저장됩니다.
- AI 동료는 **내 브라우저 안에서만** 움직이고 대화합니다. 실제 접속자에게는 보이지 않고, 초대 링크로 만난 피클끼리의 실시간 동기화에는 전혀 관여하지 않습니다.

## 구성

| 공간 | 내용 |
| --- | --- |
| 워크스테이션 | 벤치 데스크 3열, 듀얼 모니터, 메시 의자, 스탠드, 서류 트레이 |
| 유리 회의실 | 장방형 회의 테이블, 8석, 벽면 프레젠테이션 모니터 |
| 탕비실 · 라운지 | 에스프레소 스테이션, 냉장고, 정수기, 패브릭 소파와 커피 테이블 |
| 포커스 팟 | 유리 부스 3개, 데스크·노트북·서가 |

## 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 이동 | 화면을 클릭하거나 `W A S D` / 방향키 (유리 파티션은 문으로 돌아갑니다) |
| 대화 | 오른쪽 대화창에 입력 (말풍선이 머리 위에 뜹니다) |
| 상태 바꾸기 | 왼쪽 내 카드의 `업무중 · 회의중 · 자리비움 · 외근중` |
| 내 피클 설정 | 오른쪽 위 **내 피클** — 이름, 주인 이름, 몸통·귀·빛 색 |
| 업무 메모 | 오른쪽 **업무 메모** 탭에서 추가·체크·삭제 |
| 초대 | 오른쪽 위 링크 버튼 → 초대 링크 복사 |

## 실시간 동기화

- 기본은 **공개 MQTT 브로커**(EMQX → HiveMQ → Eclipse 순서로 자동 연결)로 설정 없이 바로 동작합니다.
- 브로커에 닿지 않으면 **같은 브라우저의 탭끼리**만 동기화되는 로컬 모드로 자동 전환됩니다. (오른쪽 위 상태 표시가 `연결됨` / `로컬`)
- 원하면 **내 피클 → 실시간 동기화**에 Firebase Realtime Database 주소를 넣어 업무 메모와 대화를 영구 저장할 수 있습니다.

## 파일

```
index.html      화면 뼈대
style.css       디자인 (데스크톱·아이폰 대응)
js/mqtt-lite.js 의존성 없는 최소 MQTT-over-WebSocket 클라이언트
js/net.js       브로커 연결·탭 간 동기화·Firebase 저장
js/art.js       오피스 도면과 피클 캐릭터 (Canvas)
js/app.js       상태·이동(길찾기)·대화·업무 메모·설정
```

빌드 도구 없이 정적 파일만으로 동작합니다. GitHub Pages(`main` 브랜치 루트)에 그대로 올리면 됩니다.
